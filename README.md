# Aperture

IEEE 370 S-parameter workbench.

**Live site: [https://akhil3r.github.io/](https://akhil3r.github.io/)**

Open Touchstone `.s1p`–`.sNp` files in the browser. De-embed with IEEE 370 (NZC / ZC 2x-Thru), check passivity, causality, and fixture quality, plot TDR (impedance vs time or distance), convert mixed-mode SDD11, terminate unused ports, and overlay CSV limit lines. A reference kit is built in so you can verify the algorithms.

`index.html` is a single self-contained file — no server, no install.
